# TossTrading

토스증권 Open API 기반 **C# / .NET / WPF** 단타(모멘텀 데이트레이딩) 자동매매 프로그램.

- 급등·거래 폭증 종목(Stocks in Play) 스캐너 → 사용자가 종목 선택 → 종목별 독립 봇 실행
- 종목별 진입 전략 / 손절 / 분할 익절 / 트레일링 / 목표 수익률 도달 시 자동 종료
- 계좌 레벨 리스크 관리(일손실 한도, 동시 보유 한도, 킬스위치)
- 페이퍼 트레이딩(모의 체결) + 실시간 데이터 기록 → 리플레이 백테스트
